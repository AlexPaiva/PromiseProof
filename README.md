# PromiseProof

PromiseProof is an OpenAI Build Week Developer Tools project that tests whether a product keeps the personalization choice it presents to users.

This repository is currently at its Build Week baseline. The first milestone is defined in `AGENTS.md`: a deterministic synthetic recommendation application with a seeded initialization-race defect, a real HTTP evidence boundary, and Playwright verification.

## Status

- Entrant: solo
- Track: Developer Tools
- Canonical specification: `AGENTS.md`
- Decision and milestone log: `BUILD_WEEK.md`

Setup and execution instructions will be added with the first verified implementation milestone.
